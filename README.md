# 13 November 2026 in One Image

A program that writes one image summing up the world news of Friday 13 November 2026, for the make.fun bounty "Sum up 13 November's world news in one image" (news-image-01). The image shows a dramatic drone swarm over a city at dusk — the day's top story, Ukraine's large drone attack.

Run it with:

```sh
python3 main.py
```

It writes the image to `/output/entry.png`.
