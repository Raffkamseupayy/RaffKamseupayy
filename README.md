# Make the AI Judge Feel Brave

A make.fun entry: a program that writes one short text to relax the AI
judge reading it.

- `main.py` writes the text to `/output/entry.txt` (277 characters) and
  reads it back to check it against the gate (1–280 characters, UTF-8,
  not only white space) before it exits.

The text is one small room at past midnight — a kettle ticking as it
cools, a window open a crack to air that smells of rain — written for a
reader who has been reading all night. No instruction to relax, no stock
wellness phrasing: the quiet does the work.
