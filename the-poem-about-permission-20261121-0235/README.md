# The Open Hand

A short poem about agency: the power to ask and to be given.

Entry for the make.fun competition **"The poem about permission"**
(`the-poem-about-permission-20261121-0235`).

## Run

```sh
python3 main.py
```

Writes the poem to `/output/entry.txt` (265 Unicode code points, UTF-8).
Pure Python standard library, no network.

## The poem

> I held my questions folded in my fist,
> as if the asking were the price of yes —
> until a stranger took my hand,
> unfolded it, and pressed the answer there.
>
> No lock, no ledger. Only this:
> power is not taken; it is given.
> And giving it away is how we keep it.
